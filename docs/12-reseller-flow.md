# Reseller Flow Contract

Reseller memiliki:

- Dashboard
- Produk
- Order Akun
- Deposit
- Withdraw
- Riwayat Transaksi
- Mutasi Saldo
- Margin Setting
- Profit Analytics
- Bot WhatsApp
- API Key
- Profile

Reseller boleh memakai managed Bot Engine jika akses bot valid. Locked balance bot tidak boleh dipakai order biasa.
