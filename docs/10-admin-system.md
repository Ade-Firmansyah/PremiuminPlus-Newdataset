# Admin Flow Contract

Admin mengelola:

- dashboard finance
- users
- products provider/manual/hybrid
- pricing dan markup
- Premku API key
- sync provider
- pending/manual order
- cancel/refund order
- deposits
- withdrawals
- notifications
- bot monitoring
- logs
- maintenance
- backup/restore

Admin action penting wajib tercatat di activity/admin logs dan tidak boleh bypass wallet service.
