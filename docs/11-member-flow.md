# Member Flow Contract

Member memiliki:

- Dashboard
- Produk
- Order Akun
- Deposit
- Withdraw
- Riwayat Transaksi
- Mutasi Saldo
- API Key
- Komunitas WA
- Upgrade Reseller
- Profile

Member punya API key untuk integrasi pribadi. Member tidak boleh memakai managed Bot Engine Premiumin Plus.
