# Retention And Monitoring V4

## QR Lifecycle
Direct QRIS order lifecycle is reseller-only. Pending QR records expire according to backend payment rules and must not leave dangling order state.

## Monitoring
Admin monitors deposits, withdrawals, orders, payments, balance mutations, provider status, bot sessions, and system logs.

## Dashboard Monitoring
Reseller dashboard shows active balance, deposit total, spending total, transaction total, money in/out, reseller profit, API key, recent activity, chart data, and bot summary.

## Bot Access Monitoring
Managed bot session/settings/profile are restricted to reseller/admin. Reseller managed hosting requires valid locked balance and bot access.

## Audit Events
Track registration, login, order, payment, deposit, withdraw, bot activation, maintenance toggles, backup/restore, and admin changes.
