# Wallet And Finance V4

## Reseller Wallet
Reseller can deposit, withdraw, order with saldo, use direct QRIS order, view saldo logs, and view balance mutations.

## Admin Finance
Admin can monitor deposits, withdrawals, orders, pending orders, balance mutations, revenue, provider cost, admin profit, and reseller bot profit analytics.

## Locked Balance
Locked bot balance remains owned by the reseller. Withdrawals that violate locked balance can disable bot access according to backend rules.

## Ledger Rule
Do not double credit reseller profit. Bot payment in, bot order cost, reseller profit, admin revenue, provider cost, and admin profit remain separate ledger concepts.
